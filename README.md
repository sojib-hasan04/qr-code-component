# QR Code Component

A QR code card component built as a Frontend Mentor challenge.

## Live site

[View the live site](https://magenta-babka-9f068f.netlify.app/)

## What I built

A small card with a QR code image, a heading and a short description. The card is centered on the page and fits both mobile and desktop screens.

## Built with

- Semantic HTML (`main`, `h1`, `p`, `img` with alt text)
- CSS custom properties for the colors
- Flexbox to center the card
- Flexible card width (`width: 100%` with `max-width`) so it adapts to small screens
- Outfit font loaded from Google Fonts

## What I learned

- How to structure a card with semantic HTML
- How to store colors in CSS variables and reuse them
- How to center an element on the page with Flexbox

## What I would improve

- Compare spacing and font sizes more closely with the design
- Write more of the CSS on my own before asking for help
- Make smaller, more descriptive commits
